# Agentic 写入实施

## 已确认范围

监控配置与节点生命周期允许预授权后自主执行。凭据选择全站（包含未来节点）或明确节点列表，读写共用范围；创建和注册所得节点纳入创建者范围，不增加操作权限。配置、创建、注册、轮换、删除、官方节点更新分别授权。旧凭据保持全站只读。

不开放远程命令、云主机操作、Hub 更新、管理员和 API 凭据管理、通知密钥修改。限定节点凭据不能编辑全站、动态标签或跨范围规则。注册窗口按凭据隔离。

## 写入契约

- Connect `ExecuteChange` 使用类型化操作，复用现有业务方法和提交后内存发布路径。
- 预览在实际业务事务执行校验后回滚，以显式错误阻止内存发布，返回不含凭据的前后差异与资源版本。
- 执行在同一事务重新读取凭据、校验操作及变更前后范围、比较版本、保存幂等回执与审计。
- 字段掩码用于配置修改；版本比较防止预览之后或读合并期间的并发覆盖。
- 回执查询与重试不返回一次性秘密，不存明文 token。首次执行可返回秘密；丢失后需另一次显式轮换。
- 审计仅记录白名单配置字段，不能记录原始请求或完整响应。授权和回执的备份恢复语义必须显式定义。

## 交付范围

- 主体、权限、节点范围及数据库迁移。
- 事务预览、版本校验、幂等及审计查询。
- 配置、节点生命周期、隔离注册窗口接入。
- 读范围与安全通知渠道目录。
- 面板、CLI、协议生成物、文档同步。
- 范围正反例、撤销、重试、预览不发布、迁移恢复与缺陷注入验证。
