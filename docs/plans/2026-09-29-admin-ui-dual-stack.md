## 设计约束

- 后台独立作用域：固定分组侧栏、顶栏、明暗模式、移动端抽屉；统一卡片、表单、按钮、表格、反馈。
- 总览展示真实在线数与资源摘要，不使用装饰性假数据。节点表聚焦名称、双栈地址、地区国旗、状态、流量、计费与操作。
- 节点编辑采用单一模态框，基础信息、可见性、流量、地区分组；计费另有入口。保留所有现有可编辑字段与整对象更新语义。
- 弹窗具备标题、键盘关闭、焦点约束与恢复；保存失败保留草稿；保存成功并回读后关闭，不串写节点。
- 双栈信息由 agent 独立探测，不能从 hub 的单一连接来源猜测。后台保留上报来源供诊断，不将 agent 自报出口用于鉴权或替代国家查询的可信来源。
- IPv4/IPv6 各含状态、出口地址与探测时间。尚未上报、不支持、探测失败、可用必须区分；失败不继续伪装旧地址有效。
- agent 使用固定 HTTPS 回显服务、强制 tcp4/tcp6、不走环境代理、不跟随重定向、有界响应和超时。无可用该族接口地址或明确无路由/地址族不支持时才标记不支持；其余失败保留失败状态。
- 低频后台探测，不阻塞指标采集。沿 Facts 摘要对账上报；schema 升级、快照恢复和全部管理读面同步更新，公开端不暴露地址。
