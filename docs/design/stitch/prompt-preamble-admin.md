【设计约束，必须遵守】
产品：Heron 自托管服务器监控探针的管理面板，唯一管理员使用。所有界面文字用简体中文。使用项目设计系统 Heron Monitor。
风格：深色优先的运维台（另有等价浅色），近黑中性底色，1px 细边框分层，圆角 控件 4px / 卡片 6px，不用渐变、网格背景、霓虹光效、装饰插画。正文 13px。
主色「鹭蓝」#5B9BF8 只用于链接、选中、焦点、主按钮。状态色固定：在线 #10B981、需关注 #F59E0B（到期 ≤30 天、agent 版本落后、探测失败）、离线 #F43F5E、从未上报 灰 #6B7280、维护中 #A78BFA。状态一律「色点 + 文字」。进度条 <70% 中性、70–90% 琥珀、>90% 玫红。
字体：节点名、中文、标签、按钮一律 Inter + 系统中文字体；JetBrains Mono 只用于数字、单位、时间、IP、版本号（tabular-nums）。
外壳：左侧固定侧栏 232px，顶部品牌「Heron」+ 小字「管理工作台」，导航只有这三组十四项——监控：总览、节点、探测任务；告警：告警规则、告警事件、维护静默、通知渠道；系统：外观、主题、存储、在线更新、安全、API token、注册窗口；侧栏底部「管理员」。顶栏 48px：面包屑「工作台 / 当前页」、节点快速搜索框（占位「搜索节点 ⌘K」）、「公开页 ↗」链接、明暗切换、登出图标。顶栏和侧栏不放任何其他入口、铃铛、头像菜单。
表格：表头 32px，行 36px（两行内容的行 52px），数值右对齐等宽，行操作收进 ⋯ 菜单，不在行内堆多个按钮。输入框与按钮 32px。新建与编辑一律在右侧 480px 抽屉里完成（标题、× 关闭、底部固定「保存/创建」主按钮与「取消」），不把表单铺在列表页顶部。
数据边界：管理端可见——公开页的全部字段，加上 IPv4/IPv6 出口地址及探测状态（正常 / 探测失败 / 不支持 / 等待上报）、主机名、内核、agent 版本及是否低于 hub 绑定版本（当前绑定 v0.8.0）、执行环境、上报覆盖率（必须注明它不是在线率）、私有备注、是否公开、排序、告警规则（类型只有：离线、探测、到期、资源、证书到期）、告警事件（变化只有 触发 / 恢复；带观测值、投递记录、是否处于维护静默内；另有登录成功、登录锁定、备份失败/恢复等系统事件）、维护静默、通知渠道（Telegram / Webhook）、API token、注册窗口、在线更新（hub 与各 agent 的版本、更新来源 github / hub）、存储、外观、主题、安全（会话、密码、TOTP、Passkey）。
禁止：任何可用率 / 在线率 / SLA / 99.9% 百分比、离线或维护的原因、评价性结论（「状态平稳」「健康」「良好」等）、数据里没有的规格（KVM、NVMe、线路方向、探测发包数、采样点数）、同步延迟、拓扑图、日志流、页脚、版权、通知铃铛、没有数据来源的状态徽章。
标签与地区是动态的，数量不定，站长随时增删：筛选用多选下拉（标签可搜索，已选以可移除胶囊显示，放不下折叠「+N」），不要画成固定一排胶囊。
