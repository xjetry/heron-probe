【设计约束，必须遵守】
产品：Heron 自托管服务器监控探针。所有界面文字用简体中文。使用项目设计系统 Heron Monitor。
风格：深色优先的运维台（另有等价浅色模式），近黑中性底色，1px 细边框分层，圆角 控件 4px / 卡片 6px，不用渐变、网格背景、霓虹光效、装饰插画。
主色「鹭蓝」#5B9BF8（浅色模式 #2563EB）只用于链接、选中、焦点、主按钮。状态色固定且与主色无关：在线 #10B981、需关注 #F59E0B（到期 ≤30 天等）、离线 #F43F5E、从未上报 灰 #6B7280、维护中 #A78BFA。状态一律「色点 + 文字」。进度条 <70% 中性、70–90% 琥珀、>90% 玫红。
字体：节点名、中文、标签、按钮一律 Inter + 系统中文字体；JetBrains Mono 只用于数字、单位、时间（tabular-nums）。
数据边界：只展示下列真实字段——名称、国家码、标签、公开备注（一行，可空）、在线/离线/从未上报/维护中、最后上报时间、系统、架构、虚拟化、CPU 型号与核数、运行时长、CPU%、负载 1/5/15、内存/交换/磁盘 已用与总量、网络实时 ↓↑ 速率、本周期 ↓↑ 流量、磁盘读写速率、TCP/UDP 连接数、进程数、CPU steal/iowait、按核负载、费用（金额+币种+周期）、到期日与剩余天数、历史时序图、探测（ICMP/TCP/HTTP/DNS）的目标、RTT 均值/最小/最大与丢包率、错误数。
禁止：IP 地址（探测目标除外）、主机名、内核、agent 版本、任何可用率/在线率/SLA/99.9% 百分比、离线或维护的原因、评价性结论（如「状态平稳」「无宿主竞争」「存储通畅」「路由质量良好」）、数据里没有的规格（如 KVM、NVMe、「东京 → 上海」线路方向、探测间隔、发包数、采样点数）、同步延迟、隐私模式说明、拓扑、事件日志、告警历史、页脚（版本号、API 路径、版权、链接）、手动刷新按钮、通知铃铛、额外导航菜单。
标签与地区是动态的：数量不定（0 到几十个），站长随时增删。地区用多选下拉（选项为当前节点出现的国家 + 未知，各带节点数）；标签用可搜索多选下拉，已选标签以可移除胶囊排在旁边，放不下折叠为「+N」。不要把标签或地区画成固定的一排胶囊。状态墙按数据里的国家动态分组。
不要给任何东西加没有数据来源的状态徽章或判断（如探测卡上的「正常」「健康」「良好」）；状态只有节点的四种。顶栏里不放任何导航链接。
公开页顶栏只有：鹭鸟 logo、站点标题「服务器状态」（不加 Heron 或 Heron Monitor 前缀）、「实时 · 每 2 秒」小标签、明暗切换、「登录」。
