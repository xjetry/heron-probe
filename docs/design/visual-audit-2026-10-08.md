# 视觉问题清单（2026-10-08，v0.9.0）

本地起 hub，灌入 12 个节点：在线、离线、从未上报、维护中都有，另有长名称、多标签、即将到期与已过期、流量配额、agent 版本落后。另建 3 个探测任务、4 条告警规则。历史图与对比图用合成的 24 小时序列。截图共 54 张，覆盖公开页与管理端，桌面 1440 宽与手机 390 宽，深色与浅色，用 Chromium 拍。

截图在本机 `.herdr-runs/visual-audit/shots/`（未入库），文件名形如 `a02-nodes-d-dark.png`：`p` 是公开页、`a` 是管理端，`d` 是桌面、`m` 是手机。生成脚本是同目录的 `capture.spec.ts`，放进 `web/e2e/` 后用 `pnpm exec playwright test <文件> --project=chromium` 跑。

优先级的含义：

- **P0**：看起来像坏了。
- **P1**：系统性问题，改一处 token 或全局规则就能影响全站。
- **P2**：单页的打磨。

## P0 看起来像坏了

1. **节点表的名称被徽章挤没了。** 有「agent 低于 v0.9.0」徽章或国旗的行，名称只剩「利.」「b..」「s...」。截图见 `a02-nodes-d-*`。原因是名称行不换行，名称允许收缩到 0，而国旗、「公开」胶囊和落后徽章都不收缩，名称列又只占 21%。改法：给名称一个最小宽度、让它最后才收缩；落后徽章缩成一个小图标，或移到第二行。位置：`admin.css` 的 `.node-name-line`。
2. **公开卡片的页脚错行。** 「费用」标签挂在第一行行尾，金额掉到下一行。截图见 `p02-cards-d-*`。原因是本周期改成配额口径后文字变长，比如「636 GiB / 1.0 TiB（62.1%）」「0 B（未设配额）」，而页脚两组「标签 + 数值」是在同一行里内联排的。这个问题是这次合并引入的。改法：页脚改成定宽的两列网格，本周期、费用、到期各占固定位置；未设配额时只显示用量。位置：`public/NodeCard.tsx`、`public.css` 的 `.node-card-foot`。
3. **总览实时表在 1440 宽下最右一列被裁掉。** 「最近上报」只露出一个字。截图见 `a01-overview-d-*`。原因是 `.overview-table td` 不换行，本周期列变长后总宽超出。改法：本周期列允许两行，或用更短的写法；表格内容超宽时应该能横向滚动，而不是被裁。
4. **告警事件表右侧的「投递」列被裁。** 截图见 `a11-events-d-*`。同一页的两个日期框没有标签，和上面带标签的下拉不在同一基线上。
5. **总览的手机卡片排版错乱。** 状态点独占一行，节点名跑到右上角，网速折成两行。截图见 `a01-overview-m-dark`。位置：`admin.css` 中 `.overview-table tr` 的手机网格规则，名称应该和状态点在同一行开头。
6. **台湾的旗帜显示成方框。** 截图见 `p01`、`p02`、`a02`。国旗用的是 emoji，Chromium 不渲染其中一部分，Windows 则完全不渲染国旗 emoji。改法：内置 SVG 旗帜，或只显示国家码。位置：`CountryBadge`。

## P1 系统性问题

7. **规范里的字体实际没有加载。** 规范写的是 Inter 加 JetBrains Mono，但 `styles.test.ts` 禁止 `@font-face`，页面实际用的是系统字体回退。数字用的等宽字体里还混排了中文和全角括号，比如「（剩 250 天）」「（未设配额）」「（62.1%）」，间距明显失衡。这里需要你做决定：在仓库里内置 woff2 字体（要放宽那条测试），还是把规范改成系统字体。不管选哪个，`.num` 都应该只包数字和单位，不包中文。
8. **标题层级是乱的。** 图表卡片、执行环境、Agent 运行诊断、安全页三张卡里的 `h2` 没有样式，落到浏览器默认的约 21px 粗体，比页面标题（20px）还大。截图见 `a04`、`a05`、`a15`、`p03`。改法：在全局定好 h1、h2、h3 的阶梯，例如 20 / 15 / 13，并统一字重。
9. **日期和时间的格式跟着浏览器语言走。** 截图里出现了「10/8/2026, 12:11:30 PM」、日期框的「mm/dd/yyyy」、文件框的「Choose File / No file chosen」。代码里有 23 处 `toLocaleString` / `toLocaleDateString`。改法：统一一个格式函数，输出 `2026-10-08 12:11`；日期输入与文件输入换成自绘控件，或给页面声明 `lang="zh-CN"`。
10. **服务端的英文原因直接显示在界面上。** 例如在线更新页每行都写着「agent has not reported online update support」，截图见 `a14`。改法：已知原因映射成中文，未知原因作为次要说明显示原文。
11. **链接色用得太多。** 总览表里所有节点名都是蓝色，节点页的探测图标题是蓝色大字。改法：表格里的名称用前景色，悬停时才显示链接色。
12. **行操作的 ⋯ 几乎看不见。** 所有表格都是这样，对比度太低。改法：把颜色从 faint 提到 muted，悬停整行时再加深。
13. **边框套边框。** fieldset 的框里套卡片的框，再套表格的框；告警和探测抽屉里，「作用域节点」框内又是三张带框的卡。截图见 `a07`、`a10`。改法：抽屉里的 fieldset 去掉边框，只用标题和间距分组。
14. **单行内容的表格也用 52px 行高。** 在线更新页显得很稀疏，截图见 `a14`。改法：行高按内容定，单行 36px，两行 52px。
15. **告警事件的「观测值」没有单位。** 离线事件显示「39.226」，流量事件显示「90」，到期事件显示「-3」。改法：按规则类型格式化，分别显示为时长、百分比、天数。

## 处理情况

P0 与 P1 已修，修完按同一份脚本重拍核对过。和上面建议不同的处理：

- **6 国旗**：没有内置 SVG，全站只显示国家码小标签；地区筛选与状态墙分组只写地区名。
- **7 字体**：仍不内置字体。等宽字体栈在 `monospace` 之前补了界面用的中文字体，`.num` 里漏进的中文按界面字体回退；本周期、到期等读数把中文说明拆到 `.num` 外面。价格里的「/ 月」仍在 `.num` 内。
- **9 日期**：文字里的时刻统一为 `YYYY-MM-DD HH:mm:ss`（`lib/format` 的 `dateTime` / `day`，图表刻度同源）。日期框与文件框是浏览器原生控件，显示语言跟浏览器界面语言走，`lang="zh-CN"` 改变不了；中文浏览器下显示中文，没有换成自绘控件。
- **12 行操作 ⋯**：看不清的原因是三个点用零长线段画，点径等于描边宽度，不到 1.5px；改成小圆环，悬停整行时加深。
- **14 行高**：原因是勾选框继承了控件的 32px 最小高度，清掉后单行表格回到 36px。

重拍时看到、留给 P2 的：节点表「本周期」列会在「1.0 TiB」中间折行；手机上告警事件仍是横向滚动的表格，「变化」「投递」两列折行后行变高。
